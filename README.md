# Promise & Risk of AI: Labs

Hands-on measurements behind [Promise & Risk of AI](https://promiseandrisk.ai/labs/) episodes. Each folder is one lab: the question, the scripts, the unedited output, and the result.

| Lab | Question | Episode |
|---|---|---|
| [batching-on-apple-silicon](batching-on-apple-silicon/) | How much more does one chip produce when it answers requests in batches? | Season 4 finale |
| [clef-on-apple-silicon](clef-on-apple-silicon/) | Does Cloudflare's open decision model run on a Mac Studio, and what does 4-bit change? | Model evaluation, Oct 2026 |
| [mini-soc](mini-soc/) | Can a local model on one Mac do first-line security triage without being trusted to close anything? | Build log |
